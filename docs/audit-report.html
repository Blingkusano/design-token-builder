  2. Body — consolidate the prohibitions currently scattered across Phases 4, 5, 7 and Appendix B into one headed ## Do / ## Don't block. Criterion 5 already passes on the MUST/NEVER equivalence, but a single block is easier to maintain and harder to contradict as the skill grows.
  3. Phase 2d — the Noto Sans Thai default ties a generic generator to one regional market. Consider a neutral default with Noto Sans Thai offered as a named option, so the skill reads as region-agnostic in a public repository.
