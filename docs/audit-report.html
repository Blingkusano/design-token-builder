  2. เขียนกำกับข้อจำกัดของ band 400–700 เมื่อเจอ secondary โทนกลาง — เมื่อ secondary-500 เป็นสีอย่างส้มหรือเหลือง จะไม่มี token ใดใน band นี้ผ่าน AA บนพื้นนั้นเลย (ทั้ง content.white และ content.base-primary ตก) กฎ fallback ไป background.brand-solid เขียนไว้แล้ว แต่ควรใส่ตัวเลขตัวอย่างกำกับให้เห็นว่าเมื่อไหร่จะเจอ
  3. อัปเดต docs/instruction.html — ยังอธิบายพฤติกรรมของ 1.0.0 อยู่ ทั้งลำดับ deliverable และชื่อ weight แบบเดิม ต่างจากที่ skill ทำจริงใน 1.1.1
