Instruction

วิธีใช้งาน design-token-builder

Skill สำหรับสร้างชุด Design Token ตามมาตรฐาน W3C DTCG พร้อม HTML preview และสร้าง Variables ลง Figma ให้อัตโนมัติ

เวอร์ชัน1.0.0 — ใช้เวอร์ชันล่าสุดที่อยู่บน repo เสมอ
ผลลัพธ์ไฟล์ Token JSON, ไฟล์ HTML preview และ (ถ้าเลือก) Figma Variables + หน้า Foundation
ต้องมีบัญชี Claude แผน Pro ขึ้นไป, Figma connector และไฟล์ Figma ที่แก้ไขได้
เวลาที่ใช้ประมาณ 15–30 นาที ขึ้นกับจำนวน theme และ brand
ตัวอย่างผลลัพธ์เปิดดูตัวอย่าง HTML preview — สร้างจากค่าสมมติ ไม่ใช่โปรเจกต์จริง
01

สิ่งที่ต้องเตรียมก่อนการใช้งาน

  1. 1.1

    ดาวน์โหลด skill เวอร์ชันล่าสุด

    ดาวน์โหลดไฟล์ .zip เวอร์ชันล่าสุด — ลิงก์นี้ชี้ไปที่ release ล่าสุดเสมอ ไฟล์ที่ได้พร้อมอัปโหลดทันที ข้ามไปทำข้อ 1.2 ได้เลย

    หรือถ้าอยากดูไฟล์ก่อน ดาวน์โหลดโฟลเดอร์ design-token-builder จาก repo ตรงๆ ก็ได้ แล้วบีบเป็น zip เอง

    ภายในโฟลเดอร์ต้องมีครบตามนี้:

    ไฟล์หน้าที่
    SKILL.mdตัวคำสั่งหลัก
    reference/ไฟล์อ้างอิง 6 ไฟล์ ขาดไม่ได้แม้แต่ไฟล์เดียว
    CHANGELOG.mdประวัติเวอร์ชัน

    บีบเป็นไฟล์ .zip โดยให้ โฟลเดอร์ design-token-builder เป็นตัวนอกสุด ไม่ใช่บีบไฟล์ลอยๆ เข้าไป และชื่อโฟลเดอร์ต้องตรงกับชื่อ skill

  2. 1.2

    ติดตั้งลง Claude

    เปิดสิทธิ์ก่อน แล้วค่อยอัปโหลด ทำครั้งเดียวจบ

    1. เข้า claude.ai แล้วกดรูปโปรไฟล์มุมล่างซ้าย → Settings
    2. ไปที่ Capabilities แล้วเปิด Code execution and file creation — ถ้าไม่เปิด skill จะไม่ทำงาน
    3. กลับมาที่เมนู Customize → Skills
    4. กดปุ่ม + หรือ Add แล้วเลือก Upload skill
    5. เลือกไฟล์ design-token-builder.zip ที่เตรียมไว้จากข้อ 1.1
    6. รอสักครู่ให้ขึ้นในรายการ แล้ว toggle เปิด ให้เป็นสถานะใช้งาน
    ถ้าใช้แผน Team หรือ Enterprise: เจ้าของ workspace ต้องเข้าไปเปิดทั้ง Code execution and file creation และ Skills ที่ Organization settings → Skills ก่อน ผู้ใช้ทั่วไปถึงจะอัปโหลดได้
  3. 1.3

    เตรียมไฟล์ Figma เปล่า

    สร้างไฟล์ Figma Design ใหม่แบบว่างๆ ไว้ 1 ไฟล์ เพื่อให้ Claude เข้าไปสร้าง Variables และหน้า Foundation ให้

    ต้องมีรายละเอียด
    ประเภทไฟล์Figma Design (URL ขึ้นต้นด้วย /design/)
    สิทธิ์ต้องเป็นสิทธิ์ แก้ไขได้ ไม่ใช่ view only
    สถานะไฟล์เปล่า ไม่มี variable collection เดิมค้างอยู่
    URLก๊อป URL ของไฟล์เก็บไว้ เดี๋ยว Claude จะขอ
  4. 1.4

    ต่อ Figma connector เข้ากับ Claude

    เตรียมไฟล์ Figma อย่างเดียวไม่พอ Claude ต้องมีสิทธิ์เข้าไปเขียนในไฟล์นั้นด้วย ถ้าข้ามขั้นนี้ ทุกอย่างจะทำงานปกติจนถึงตอนสร้าง Variables แล้วค้าง

    1. ที่ claude.ai กดรูปโปรไฟล์มุมล่างซ้าย → Settings → Connectors
    2. กด Browse connectors แล้วค้นคำว่า Figma
    3. กด Connect แล้วอนุญาตสิทธิ์ผ่านหน้า Figma ที่เด้งขึ้นมา
    4. กลับมาที่แชท เปิด toggle Figma ในเมนูเครื่องมือใต้ช่องพิมพ์
    5. ทดสอบด้วยการพิมพ์ว่า “อ่านไฟล์ Figma นี้ให้หน่อย” พร้อมวาง URL ถ้าตอบกลับมาได้คือพร้อมใช้งาน
    บัญชี Figma ที่ใช้ต่อ connector ต้องเป็นบัญชีที่ มีสิทธิ์แก้ไขไฟล์นั้นจริง ต่อด้วยบัญชีที่เห็นไฟล์แบบ view only จะสร้าง Variables ไม่ได้
  5. 1.5

    เตรียมค่าสีและฟอนต์ของแบรนด์

    Claude จะถามค่าพวกนี้ทีละข้อในขั้นตอนที่ 2.2 และจะไม่เริ่มสร้าง token จนกว่าจะได้ครบ เตรียมไว้ก่อนจะได้ไม่ต้องหยุดไปเปิดไฟล์ brand กลางบทสนทนา

    รายการต้องเตรียม
    ชื่อโปรเจกต์ใช้ขึ้นหน้า Cover ใน Figma
    Primaryค่า hex สีหลักของแบรนด์ — จำเป็น ไม่มีค่าเริ่มต้นให้
    Secondaryค่า hex — ถ้าไม่มี Claude จะเสนอ 3 ตัวเลือกให้
    Neutralค่า hex — ถ้าไม่มี Claude จะเสนอ 3 ตัวเลือกให้
    Accentค่า hex — ถ้าไม่มี Claude จะเสนอ 3 ชุดพาเลตต์ให้เลือก
    Status 4 สีhex ของ Success / Warning / Error / Info
    ฟอนต์ชื่อ font family ที่แบรนด์ใช้ (ค่าเริ่มต้นคือ Noto Sans Thai)
    ขนาดฐานขนาดตัวอักษรพื้นฐาน (ค่าเริ่มต้นคือ 16px)
    Themeต้องการ Light/Dark ไหม และมี custom theme เพิ่มไหม
02

เริ่มคำสั่งการสร้าง design token

  1. 2.1

    เปิด Claude แล้วสั่งสร้าง token

    เปิดแชทใหม่ แล้วพิมพ์คำสั่งพร้อมเรียกชื่อ skill

    › สร้าง design token ให้หน่อย /design-token-builder
  2. 2.2

    ตอบชุดคำถามจาก Claude

    Claude จะถามทีละข้อเพื่อเก็บเป็น requirement ตอบให้ครบทุกข้อ ระบบจะไม่เริ่มสร้าง token จนกว่าจะได้ข้อมูลครบ

    ลำดับคำถาม
    1ชื่อโปรเจกต์ (ใช้ขึ้นหน้า Cover ใน Figma)
    2–6ค่าสี: Primary, Secondary, Neutral, Accent และ Status ทั้ง 4 (Success / Warning / Error / Info)
    7ต้องการ Light/Dark mode ไหม และมี custom theme เพิ่มไหม
    8ฟอนต์และขนาดฐาน
    9แพลตฟอร์มปลายทาง: Mobile App หรือ Webview หรือทั้งคู่
  3. 2.3

    ตรวจสอบ HTML preview

    Claude จะส่ง Token JSON พร้อมไฟล์ HTML preview มาให้ เปิดไฟล์ preview แล้วไล่ดูให้ครบทุกหมวด — Color, Typography, Spacing, Radius, Elevation, Border และ Focus ring

    ถ้าต้องการแก้: พิมพ์สั่งแก้ได้เลยในแชทเดิม เช่น

    › ปรับ radius md เป็น 12px แล้วออก preview ใหม่
    (Optional) เก็บ Token JSON ไว้ส่ง developer
    ถ้าต้องการส่งต่อให้ทีม developer เอาไปใช้ ให้ดาวน์โหลดไฟล์ Token JSON เก็บไว้ด้วย ไฟล์นี้คือของที่เอาไปต่อกับโค้ดได้จริง ส่วน HTML preview มีไว้ตรวจด้วยตาเท่านั้น
  4. 2.4

    ตอบ Y/N เพื่อสร้างลง Figma

    เมื่อตรวจ preview เรียบร้อยแล้ว ไม่ต้องพิมพ์คำสั่งอะไรเพิ่ม Claude จะถามเองเป็นคำถาม Y/N ให้ตอบตามที่ต้องการ

    คำถามมี สองข้อ แยกกันคนละเรื่อง ตอบ Y ข้อแรกไม่ได้แปลว่าข้อสองจะถูกข้ามไป จะโดนถามทั้งสองข้อเสมอ

    คำถามตอบ Y แล้วได้อะไร
    “Create variables to Figma? (Y/N)” สร้างโครงหน้าและ Variables ทั้ง 3 collection ลงไฟล์ Figma แล้วหยุดให้ตรวจ — ยังไม่ทำ QA รอบสุดท้าย
    “Would you like to create a design style guideline file directly on Figma?” ทำต่อจนครบ ทั้งหน้า Foundation ทุกหน้าและ QA รอบสุดท้าย (ตรวจชื่อซ้ำ ตรวจว่าไม่มีค่า hardcode ตรวจสลับ Light/Dark)
    อยากได้ครบทั้งชุด ให้ตอบ Y ทั้งสองข้อ — ถ้าตอบ N ข้อแรกแต่ตอบ Y ข้อสอง ก็ยังได้ผลครบเหมือนกัน เพราะข้อสองครอบคลุมงานของข้อแรกอยู่แล้ว

    ระหว่างทาง Claude จะขอ URL ของไฟล์ Figma ที่เตรียมไว้จากข้อ 1.3 และจะหยุดให้ยืนยันอีกครั้งก่อนปิดงาน
